# 04 独立プロジェクト開始指示（貼り付け用）

このプロジェクトは「製造システム動作モデル・要求定義支援基盤」の開発です。添付の `01_PROJECT_CHARTER.md`、`02_REQUIREMENTS_V0_1.md`、`03_ROADMAP_AND_HANDOFF.md` を初期資料として扱ってください。

目的は、工程担当者と装置動作・MESとの情報授受を画面で確認し、装置固有の差分をステップ別に記録し、議事録を根拠にモデルを改訂し、最終的にメーカー・MESベンダーとの要求仕様協議に活用することです。現段階では要求定義レベルの動作イメージを扱い、コマンド・PLC・DBなどの詳細設計は行いません。

作業原則：
1. 「確定／仮定／未決／提案」を区別し、未決事項を勝手に確定しない。
2. 共通モデル・装置類型モデル・個別装置モデルを分離する。
3. 装置動作・状態遷移・簡易シーケンス表現は同一のシナリオデータから生成する。
4. 装置ID・シナリオID・固定ステップID・コメントID・要求IDを使って根拠を追跡できるようにする。
5. 会社固有の情報は会社環境だけで扱い、公開GitHubには置かない。
6. Copilotによる生成文を正式に承認された要求と混同しない。

最初の作業は、添付資料の整合性と未決事項を点検し、Phase 1で定義する最小データ構造、代表シナリオ、画面構成の設計順序を提案することです。実装を始める前に、確認が必要な判断事項を優先順位付きで示してください。
