# Copilot引継ぎパッケージ（2026-11-02）

## このパッケージの用途

ChatGPT側での詳細設計を一旦区切り、会社Copilot側で既存HTML/JavaScriptシミュレーターを修正・検証するための資料一式。**会社での正式な運用開始を承認する資料ではない。**

## 読む順番

1. `05_HANDOFF_SPEC_V0_3.md`：**最新の決定事項・未決事項・実装不足・確認項目。最優先。**
2. `06_COPILOT_WORK_ORDER.md`：Copilotに最初に渡す作業指示。
3. `01_PROJECT_CHARTER.md`、`02_REQUIREMENTS_V0_1.md`、`03_ROADMAP_AND_HANDOFF.md`：当初の目的・要求・移行条件。
4. `04_COPILOT_START_PROMPT.md`、`00_README.md`：初期指示と履歴。
5. `L2_comment_review_v0_2.zip`：現行試作。ZIPを展開して`index.html`と同梱JSONを確認。

**優先順位**：最新文書（05） ＞ 当初資料（00～04）のうち矛盾する箇所。試作ファイルは「実装の事実」を示すが「仕様の承認」を示さない。

## 重要事項

- コメントは初期運用で「1コメント＝1装置」「1ファイル＝1装置」。現行試作は全件一括出力なので改修が必要。
- 装置マスターは主導者が正式版を用意。現行試作には仮装置3件が埋め込まれている。
- Copilotによる改訂は案であり、正式なMES・装置要求の決定ではない。
- 社内情報は会社の許可された環境だけで扱う。

## 判定

**会社Copilotへの開発引継ぎ：可能。初期運用開始：P0改修と会社環境での検証まで保留。**
